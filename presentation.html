DocuQuiz

An AI-powered examination platform that transforms documents into intelligent assessments. Upload two documents and let advanced AI uncover deep understanding, detect plagiarism, and provide comprehensive evaluation with autonomous reference verification.

Core Capabilities

01

Intelligent Assessment

Adaptive examinations that challenge candidates at appropriate difficulty levels based on document complexity and answer quality.

02

Plagiarism Detection

Multi-layer detection identifies verbatim copying, paraphrasing, and AI-generated responses through advanced analysis.

03

Autonomous Verification

V2 API: Claude autonomously verifies claims against documents using tool-calling agentic loops for reliable fact-checking.

04

Real-Time Feedback

Instant grading with constructive feedback on each answer, enabling immediate learning and adaptation.

05

Comprehensive Reports

Detailed examination summary with grades, verdicts, plagiarism results, and actionable insights per question.

06

Exam Integrity

Multiple verification layers ensure integrity: plagiarism detection, AI identification, off-topic filtering, and reference verification.

V1 vs V2 Comparison

V2 introduces autonomous reference lookup through agentic tool-calling, enabling Claude to verify claims directly against documents during evaluation. V1 remains available for backward compatibility.

Endpoint /api/quiz/answer /api/quiz/v2/answer
Evaluation Method Direct prompt chains Tool-calling agentic loops

When to Use Each Version

Use V1 When:

  • Quick evaluations needed
  • Lower token usage preferred
  • Existing V1 integration
  • Latency sensitive

Use V2 When:

  • High-stakes assessment
  • Accurate plagiarism detection
  • Verifiable reasoning required
  • Interview/certification use

How It Works

1

Upload Documents

Start by uploading two reference documents (position description and job offer) in TXT or MD format. Both files are required.

2

Answer Adaptive Questions

AI examiner generates insightful questions testing deep understanding of document concepts. Difficulty adjusts based on performance.

  • 10-20 adaptive questions
  • Real-time feedback on each answer
3

Instant Evaluation

V2: Each answer evaluated with autonomous reference verification using tool-calling agentic loops.

  • Grade: 0-10 based on understanding
  • Trust Score: Originality assessment (0-10)
  • Plagiarism: ORIGINAL / COPY / AI
  • References Verified: Audit trail
4

Comprehensive Summary

Upon completion, receive detailed results with all questions, answers, grades, verdicts, and actionable feedback.
