How It Works

1

Upload Documents

Start by uploading two reference documents (position description and job role description) in TXT or MD format.

  • Drag and drop or click to upload
  • Both files required to proceed
2

Answer Questions

AI examiner generates insightful questions testing deep understanding of document concepts and technical seniority.

  • 10-20 adaptive questions
  • Real-time feedback on each answer
  • Difficulty adjusts based on performance
3

Real-Time Evaluation

Each answer is evaluated instantly using LangChain AI chains that analyze multiple dimensions.

  • Grade: 0-10 based on understanding and relevance
  • Trust Score: Originality of the answer (0-10)
  • Plagiarism Detection: ORIGINAL, COPY, or AI generated
  • Off-topic Detection: Relevance to examination theme
4

Summary & Analysis

Upon completion, receive comprehensive results showing all questions, answers, grades, verdicts, and actionable feedback.

  • Average grade and scores
  • Detailed breakdown of each answer
  • Plagiarism and AI detection results
  • Constructive feedback per question

Data Flow & Processing Pipeline

📄 Documents
→
📝 Session Store
→
🤖 AI Chains
→
📊 Results
Process Flow:
1. User uploads documents → Created in-memory session
2. First question generated via LangChain Question Chain
3. User submits answer → Sent to Evaluation Chain
4. Chain analyzes: originality, plagiarism, grade, off-topic score
5. Decision: Continue with new question OR stop examination
6. Final summary aggregates all results and generates comprehensive report

Core API Endpoints

POST /session
Create new session with uploaded documents
POST /answer
Submit answer, receive evaluation & next question
GET /session/{id}/summary
Retrieve final examination summary and results
